
# **BigTech**

BigTech is a React-based application designed to manage products efficiently. Users can add, update, delete, and view details of products seamlessly.

## **Features**
- **Product Management**:
  - Add products with essential details such as model name, brand, type, description, image, and price.
  - View product list with options to see details, update, and delete products.
- **My Cart**:
  - Add products to the cart with a real-time total price calculation.
  - Remove unwanted items with a delete button.

## **Tech Stack**

### **Frontend:**
- **React.js**: Framework for building dynamic and interactive user interfaces.
- **CSS Frameworks**:
  - **Tailwind CSS**: Modern utility-first styling framework.
  - **daisyUI**: Pre-built styled components for faster UI development.
- **JavaScript (ES6)**: Enables efficient and dynamic app functionality.
- **React Router**: Provides seamless navigation and routing in the application.
- **Firebase Hosting**: For secure and reliable frontend deployment.

### **Backend:**
- **Node.js**: Handles server-side functionality.
- **Express.js**: Backend framework for routing and middleware integration.

### **Database:**
- **MongoDB**: NoSQL database to manage product and user data.

### **Hosting:**
- **Vercel**: Deploys the React application for global accessibility.

### **Development Tools:**
- **VS Code**: The primary code editor for development.
- **Git**: Version control for collaboration and tracking changes.

## **Installation**

### **Prerequisites:**
- Install [Node.js](https://nodejs.org/).
- Install `npm` (comes with Node.js).

### **Steps:**
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/BigTech.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BigTech
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open the app in your browser at `http://localhost:3000`.
